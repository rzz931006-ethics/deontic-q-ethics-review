双引擎架构 道义逻辑 + Q-Learning
O道义逻辑层

将政策法规中的规范语句形式化为 O(应当)、F(禁止)、P(允许) 三元算子，形成可计算的伦理规则库，作为审查依据与 Q 表先验知识。

O 义务规则F 禁令规则P 许可规则
QQ-Learning 决策层

智能体以「风险状态」为观察、以「审查决定」为动作，通过 ε-greedy 探索与 TD 更新学习最优审查策略，输出带置信度的决策建议。

Q 表热力图学习曲线
R可反馈闭环

审查决定产生后，用户可反馈「合理 / 不合理」，反馈转化为奖励信号回传 Q 表；系统策略随反馈持续演化，实现「审查—反馈—再学习」闭环。

DEONTIC RULE BASE

道义逻辑规则库

从第一轮训练语料中形式化提取的伦理规范，每个命题以「应当 O / 禁止 F / 允许 P」算子表达，并可溯源至具体法规条款。规则库是审查工作台道义判定的依据，也是 Q 表先验知识的来源。

REVIEW WORKBENCH

伦理审查工作台

选择送审案例（或自定义风险画像），系统将运行「道义规则判定 + Q-learning 决策」，出具带程序分流与规则依据的审查意见书；随后可对决定进行反馈，驱动策略更新。

INTELLIGENT RISK ASSESSMENT

智能风险研判

专家或使用者用自然语言描述送审项目，系统从三方面综合判断风险等级：① 既往事例 / 训练数据比对（与案例库相似度）、② 语义风险特征识别、③ 伦理标准与政策规则（道义逻辑 O / F / P 依据）。研判结果可一键送入审查工作台。
